# Z Client Updates

Hier liegen die automatischen Updates fuer den Z Client.
Der Launcher laedt das neueste Release automatisch - nach dem naechsten Minecraft-Neustart ist es aktiv.

## Zync (Chat-App)

Im Ordner [`zync/`](zync/README.md) liegt **Zync** – eine moderne Chat-, Voice- und Streaming-App
(Web, Handy-App und Desktop-App). Anleitung und Features: [`zync/README.md`](zync/README.md).

## Butterfly-Messer (Ressourcenpaket)

Im Ordner [`minecraft/butterfly-messer/`](minecraft/butterfly-messer/README.md) liegt ein 3D-Butterfly-Messer
für Minecraft 1.21.11 mit Inspect, Flips, Leuchtspur und vier Farben (Ressourcenpaket + optionales Datenpaket),
dazu der kleine Fabric-Mod [`minecraft/zknife-hand/`](minecraft/zknife-hand/README.md), der in der Ego-Sicht deinen
echten Minecraft-Arm mit dem Messer zeigt.
